## 先记住三个概念

| 名称 | 本地示例 | 用途 |
| --- | --- | --- |
| DataAgent 管理库 | `saa_data_agent` | 保存智能体、模型配置、数据源配置、知识、会话等项目元数据。 |
| 业务数据源 | `product_db`、`employment_db` | 被智能体实际查询的数据。不要把管理库当作分析对象。 |
| Schema 初始化 | 数据源页面的“初始化数据源” | 将已选表及字段信息向量化，供后续 Schema 召回。不是导入业务数据。 |
