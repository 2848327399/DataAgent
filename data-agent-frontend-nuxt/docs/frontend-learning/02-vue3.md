# 02：用本项目学 Vue 3

## 1. `.vue` 文件的三部分

Vue 单文件组件通常由三块组成：

```vue
<template>
  <!-- 界面结构 -->
</template>

<script setup lang="ts">
// 状态与行为
</script>

<style scoped>
/* 当前组件样式 */
</style>
```

建议阅读顺序是 `template -> script -> style`：先知道用户看见什么，再找交互函数和数据，最后研究外观。

最短的真实页面是 [pages/chat.vue](../../app/pages/chat.vue)。它的模板只是组合三个子组件，而初始化和清理逻辑放在 script 中。

## 2. 模板语法

### 文本和属性绑定

```vue
<span>{{ agent.name }}</span>
<v-img :src="agent.avatar" />
<v-btn :disabled="loading">保存</v-btn>
```

双花括号把数据输出成文本。属性名前的 `:` 是 `v-bind:` 简写，右侧会按 JavaScript 表达式求值；没有 `:` 的属性通常是固定字符串。

### 事件

```vue
<v-btn @click="createAgent">创建</v-btn>
<input @change="handleFileUpload" />
```

`@click` 是 `v-on:click` 的简写。顺着事件函数名到 `<script setup>` 中搜索，是阅读交互逻辑最快的方法。

### 条件和循环

```vue
<div v-if="loading">加载中</div>
<div v-else>加载完成</div>

<div v-for="agent in agents" :key="agent.id">
  {{ agent.name }}
</div>
```

`v-if` 决定元素是否存在；`v-show` 通常只切换 CSS 显隐。`v-for` 必须尽量提供稳定且唯一的 `key`，通常使用后端 id。

### 双向绑定

```vue
<v-text-field v-model="agentForm.name" />
```

输入框显示 `agentForm.name`；用户输入时又会更新它。这就是双向绑定。它可以理解为“传入当前值 + 监听更新事件”的语法糖。

## 3. 响应式核心

### `ref`

```ts
const loading = ref(false);
loading.value = true;
```

在 script 中读写 `ref` 使用 `.value`；在 template 中 Vue 会自动解包，可以直接写 `loading`。项目里的布尔状态、数组、当前选中项多使用 `ref`。

### `reactive`

```ts
const form = reactive({ name: '', status: 'draft' });
form.name = '销售助手';
```

`reactive` 适合把一个对象整体变成响应式对象，不使用 `.value`。新建智能体页面的 `agentForm` 是真实例子，见 [pages/agent/new.vue](../../app/pages/agent/new.vue)。

初学时可遵循：基本值、数组、可能整体替换的对象优先 `ref`；作为一个整体持续修改字段的表单可以用 `reactive`。

### `computed`

```ts
const currentAgentId = computed(() => {
  const value = route.query.agentId;
  return value ? Number(value) : undefined;
});
```

`computed` 是由其他响应式数据推导出的值。依赖不变时会复用结果，不应在其中发送请求或随意修改其他状态。

### `watch`

```ts
watch(currentAgentId, async (newId, oldId) => {
  if (newId && newId !== oldId) await init(newId);
});
```

`watch` 在依赖变化后执行副作用，例如重新加载数据、滚动到底部。能用 `computed` 表达“结果”时用 computed；需要“变化后做某事”时用 watch。

## 4. 生命周期

```ts
onMounted(() => loadData());
onUnmounted(() => disconnect());
```

- `onMounted`：组件已经挂到浏览器页面后执行，常用于首次请求、DOM 操作、注册事件。
- `onUnmounted`：组件离开页面时执行，必须清理定时器、事件监听和流连接。

[pages/chat.vue](../../app/pages/chat.vue) 在挂载时初始化聊天，在卸载时断开会话 SSE；[ChatInputArea.vue](../../app/components/chat/ChatInputArea.vue) 挂载时监听 document 点击，卸载时移除监听。这两个例子很典型。

## 5. 组件通信：Props、Emit、Slot

### Props：父传子

[BaseDrawer](../../app/components/BaseDrawer/index.vue) 定义：

```ts
interface Props {
  drawerWidth?: number | string;
  modelValue?: boolean;
}
const props = withDefaults(defineProps<Props>(), {
  drawerWidth: 260,
  modelValue: true,
});
```

父组件通过 `<BaseDrawer :drawer-width="280">` 传值。子组件不要直接修改 props。

### Emit：子通知父

```ts
const emit = defineEmits<{
  'update:modelValue': [value: boolean];
}>();

emit('update:modelValue', false);
```

父组件的 `v-model="drawer"` 会接收 `update:modelValue`，所以子组件可以通知父组件更新抽屉状态。

### Slot：父填内容

BaseDrawer 暴露 `drawer`、`header` 和默认插槽。布局文件这样填充：

```vue
<BaseDrawer v-model="drawer">
  <template #drawer>左侧内容</template>
  <template #header="{ toggle }">顶部内容</template>
  页面主体
</BaseDrawer>
```

Slot 适合复用结构但允许调用方提供内容。作用域插槽还能把子组件的数据或函数交给父组件使用。

## 6. Composable：复用有状态逻辑

Composable 是普通函数，但会组合 Vue 的 `ref`、`computed`、生命周期等能力，名字通常以 `use` 开头。

[useCrudPage](../../app/composables/useCrudPage/index.ts) 把列表加载、弹窗开关、表单校验、保存和删除封装起来。业务知识页面只需要提供：

- 如何加载列表 `loadFn`
- 如何创建、更新、删除
- 空表单长什么样 `defaultFormFactory`

这体现了一个重要设计：页面负责业务差异，Composable 负责可复用流程。

## 7. 自动导入为什么“没有 import 也能用”

你会在代码中看到 `ref`、`computed`、`useRoute`、`useRouter` 没有显式导入。这是 Nuxt 自动导入，不是 JavaScript 天生支持。

但项目中有些文件仍显式导入 Vue API，两种写法都能工作。初学者不要误以为任何函数都能省略 import；只对 Nuxt 约定范围和 [nuxt.config.ts](../../nuxt.config.ts) 配置的目录生效。

## 8. 一套读组件口诀

```text
看到 {{ }}       -> 去 script 找同名数据
看到 :prop       -> 判断传入的是表达式还是固定值
看到 @event      -> 去找事件处理函数
看到 v-model     -> 找被双向修改的状态
看到 v-if        -> 找控制显隐的状态
看到 v-for       -> 找数组从哪里加载
看到 store.xxx   -> 去 app/stores 找定义和 action
看到 <XxxYyy>    -> 去 components 找子组件
```
